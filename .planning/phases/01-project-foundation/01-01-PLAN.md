<task type="auto">
  <name>Task 3: Create MongoDB connection module</name>
  <files>backend/src/config/db.js</files>
  <read_first>backend/src/config/env.js</read_first>
  <action>
  Create `backend/src/config/db.js`:
  ```javascript
  const mongoose = require('mongoose');
  const { MONGODB_URI } = require('./env');

  const connectDB = async () => {
    try {
      const conn = await mongoose.connect(MONGODB_URI);
      console.log(`MongoDB connected: ${conn.connection.host}`);
    } catch (error) {
      console.error(`MongoDB connection error: ${error.message}`);
      process.exit(1);
    }
  };

  module.exports = connectDB;
  ```

  Key design decisions:
  - Use async/await with try/catch for clean error handling
  - Log the connected host for verification
  - Exit process on connection failure (fail-fast in startup)
  - Export as a function so server.js controls when connection happens
  - Mongoose 6+ no longer needs `useNewUrlParser` or `useUnifiedTopology` options
  </action>
